## Writeup Format

Every writeup follows the same structure, so they're easy to compare and skim:

- **Summary** - what the room is about, at a glance
- **Walkthrough** - numbered steps through recon and exploitation
- **Flag** - redacted (no spoilers), with a note on when the real flag gets posted, if the room is tied to a timed event
- **Lessons Learned** - what I took away from the room

## Disclaimer

These writeups are for educational purposes and reflect my own approach to solving each room. If you're stuck on a room yourself, try it on your own first before reading the solution.
